# emoji-to-icons 🚀

> Convert emojis to professional SVG icons from Lucide, Heroicons, and Material Icons.

**Status:** Initial Extraction Phase

## Features
- Semantic mapping of emojis to icons (e.g. 🧠 -> brain, 🤖 -> bot)
- Supports Lucide, Heroicons, and Material Icons

## Installation

```bash
npm install emoji-to-icons
```
